# Common references

Plain Markdown references shared by the skills. This folder is not a skill: it has no `SKILL.md`.

| File | What it covers |
|------|----------------|
| `skill-style.md` | How a skill is written |
| `skill-paths.md` | How the main session hands exact skill paths to subagents |
| `verify-method.md` | How an independent verifier checks a change against its spec |
| `research.md` | Optional, evidence-backed research |
| `persistence.md` | Feature documents, their memory copy and safe writes |

Installing copies this folder next to the skills of every agent and never deletes files you wrote.
